Từng màn hình

Những gì cần nhìn

Bảng profile

Mỗi dòng trả lời ba câu hỏi: đang chạy không, proxy ở đâu, dùng lần cuối khi nào.

  • Avatar chữ cái với huy hiệu hệ điều hành, tên + tình trạng tài khoản (Live / Die / Banned).
  • Dòng phụ: Chrome, email đăng nhập, chip nhóm.
  • Proxy: mã nước, IP đơn cách, độ trễ đổi màu khi chậm.
  • Vạch xanh bên trái và chấm nhấp nháy cho profile đang chạy.
  • Cột "Dùng gần đây" mới, hiển thị tương đối.

Chọn hàng loạt và thông báo

Thanh thao tác nổi lên khi chọn profile, neo góc dưới trái. Thông báo đồng bộ ở góc dưới phải, không bao giờ đè lên nhau.

  • Mở, Mở lưới, Dừng, Đăng nhập Gmail, Nuôi acc, Xuất, Xoá — mỗi nút có icon.
  • Toast có tiêu đề + icon theo loại: đang đồng bộ, đã xong, lưu ý, lỗi.

Thanh công cụ gọn hơn

Từ 8 nút dàn ngang xuống còn tìm kiếm, bộ lọc, Làm mới, hai menu thả xuống và nút tạo profile.

  • "Nhập / Xuất": nhập .json, nhập acc hàng loạt, xuất tất cả.
  • "Công cụ": khớp múi giờ theo proxy, hẹn giờ nuôi acc, kho proxy, đồng bộ cloud.
  • Menu dòng (⋯) có icon, chọn nhóm và trạng thái tại chỗ, copy mã 2FA.

Đăng nhập

Nền aurora xanh dương – cyan trên lưới mờ, thẻ kính, ô nhập có icon, ba huy hiệu năng lực.

  • Chuyển động chậm 14 giây, tắt khi hệ điều hành yêu cầu giảm chuyển động.

Modal

Tất cả modal dùng chung khung: tiêu đề, nút đóng vector, thẻ nội dung, chân trang tách nền. Ô nhập cao 38 px, viền sáng khi chọn.

  • Bộ chọn dạng phân đoạn (segmented) thay cho hàng nút rời.
  • Đã gỡ 109 emoji khỏi tiêu đề, nút và chuỗi trong 11 modal.

Chạy thử

Xem trên máy bạn

# trong thư mục VGCBrowser, sau khi git pull
npm install
npm run ui:preview          # chụp 10 ảnh vào test/ui-preview/shots/
npm run dev                 # chạy app thật với giao diện mới

Lưu ý

  • Cờ quốc gia chỉ hiện trên macOS; Windows dùng huy hiệu mã nước vì hệ điều hành không có font cờ.
  • Chưa chụp được cửa sổ Electron thật trên máy chủ này; ảnh trên là bản dựng renderer với dữ liệu mẫu.
  • Chưa commit. Bản vá đồng bộ phiên và giao diện nằm cùng thư mục làm việc.
